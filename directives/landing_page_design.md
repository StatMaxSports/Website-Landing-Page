# Stat Max Landing Page Design

## Color Palette
- **Primary Background**: Navy Blue `#0f1432`
- **Primary Accent**: Yellow `#ffaa00`
- **Secondary Accent (Minimal)**: Red `#ff001e`
- **Text / Contrast**: White `#ffffff`

## Typography
- **Headlines**: Bold, high-precision sans-serif (e.g., Inter, Montserrat, or Roboto Condensed for a tech feel).
- **Body**: Clean sans-serif with good readability.

## Sections
1. **Hero Section**: 
   - Background: Full-screen video loop showing sports clips with AI overlays (bounding boxes, trajectories, speed data).
   - Overlay: High-contrast white text (Headline: "Maximize Your Match Data").
   - Call to Action: Primary button (Yellow) "Get Started".
2. **Product Section**: 
   - Feature grid with icons/images showing the AI engine's capabilities.
3. **How It Works / Demo Section**: 
   - Step-by-step breakdown or 3-column layout showing the process (Capture -> Process -> Analyze).
4. **Lead Capture / Registration**: 
   - Centered form with clear input fields.
   - Design: Rounded containers like Linktree for a friendly feel.
5. **Footer**: 
   - Simple links and social icons.

## Animations & Interactions
- **Reveal on Scroll**: Sections should fade in as the user scrolls.
- **Button Hover**: Subtle lift and glow for yellow buttons.
- **Micro-transitions**: Smooth transitions between state changes (e.g., form validation).
